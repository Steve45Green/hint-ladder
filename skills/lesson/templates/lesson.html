Practice

1. What does this print?

int sum = 0;
for (int i = 0; i < 3; i++) sum += i;
printf("%d\n", sum);

0 + 1 + 2 = 3: the loop stops before i reaches 3.

2. With n = 5, how many times does the body of for (i = 0; i < n; i++) run?

i takes the values 0, 1, 2, 3, 4: that is n = 5 values.
