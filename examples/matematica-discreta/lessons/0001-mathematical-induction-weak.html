Mathematical induction: proving a formula for every n

By the end of this lesson you can write a complete weak-induction proof — base case and inductive step, correctly labelled — for a sum formula, in the form a marker cannot fault.

The idea

Induction proves a statement P(n) for every natural number n from some starting point n₀ onward, without checking each n one by one. It has exactly two parts:

  • Base case: show P(n₀) is true (usually n₀ = 0 or 1).
  • Inductive step: assume P(k) is true for some arbitrary k ≥ n₀ — this assumption is the inductive hypothesis (IH) — and use it to show P(k+1) is true.

Checking a few values of n is not a proof: it only shows the first few dominoes are the right shape, not that each one topples the next. Source: Rosen, Discrete Mathematics and Its Applications, "Mathematical Induction" (see RESOURCES.md).

Worked example

Claim: for every n ≥ 1, 1 + 2 + … + n = n(n+1)/2.

PartWhat you writeWhy it's needed
Base casen = 1: LHS = 1, RHS = 1·2/2 = 1. Equal.Anchors the chain at n = 1.
IHAssume 1 + 2 + … + k = k(k+1)/2 for some k ≥ 1.Lets us build P(k+1) on top of P(k).
Inductive step1+…+k+(k+1) = k(k+1)/2 + (k+1) [IH] = (k+1)(k+2)/2Shows P(k) true ⟹ P(k+1) true.
ConclusionBy induction, the formula holds for all n ≥ 1.Cites the principle — never skip this line.

The algebra in the inductive step: start from the IH, add the next term (k+1), then factor.

k(k+1)/2 + (k+1) = (k+1)(k/2 + 1) = (k+1)(k+2)/2

That last expression is exactly n(n+1)/2 with n replaced by k+1 — which is precisely what P(k+1) claims.

Practice

1. For the claim "for every n ≥ 1, 1+2+…+n = n(n+1)/2", what is the value of the right-hand side n(n+1)/2 when n = 1?

1·2/2 = 1 — matches the left-hand side (just the number 1), so the base case holds.

2. In the inductive step, what exactly do you assume?

You fix one arbitrary k ≥ n₀ and assume P(k) — that's the inductive hypothesis. You never assume P holds for all n; that's the thing being proved.

3. Now that 1+2+…+n = n(n+1)/2 is proven for every n ≥ 1, use it to compute 1+2+…+10.

10·11/2 = 55. One line, no need to add ten numbers by hand — that's the payoff of having proved the formula.

4. A student checks the formula for n = 1, 2, 3 and writes "it works, so it's proven for all n." What's missing?

Checking cases never covers the infinitely many n left untested. Only an inductive step — showing P(k) ⟹ P(k+1) for arbitrary k — closes the gap for every n at once. (A base case is present here; three correct checks include n = 1.)
