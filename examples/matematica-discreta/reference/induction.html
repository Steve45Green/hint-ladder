Mathematical induction (weak)

Proof skeleton — write all four parts, in this order

PartWhat to write
Claim"We prove P(n): <statement>, for every n ≥ n₀."
Base caseShow P(n₀) directly — plug in n₀ and check both sides.
Inductive hypothesis (IH)"Assume P(k) holds for some (arbitrary but fixed) k ≥ n₀."
Inductive stepShow P(k+1), using the IH somewhere in the derivation — say explicitly where ("by IH").
Conclusion"By the principle of mathematical induction, P(n) holds for all n ≥ n₀."

Worked template

Claim: for every n ≥ 1, 1 + 2 + … + n = n(n+1)/2.

  • Base case (n=1): 1 = 1·2/2. ✓
  • IH: assume 1+2+…+k = k(k+1)/2 for some k ≥ 1.
  • Step: 1+…+k+(k+1) = k(k+1)/2 + (k+1) [by IH] = (k+1)(k+2)/2.
  • Conclusion: true for all n ≥ 1 by induction.

Common marks lost

  • No explicit conclusion line citing the principle of induction.
  • Inductive step never actually uses the IH — then it isn't induction.
  • "Assume P(n) for all n" instead of "assume P(k) for some fixed k" — this assumes the very thing being proved.
  • Base case checked at the wrong starting value (e.g. n=0 when the claim says n≥1).
