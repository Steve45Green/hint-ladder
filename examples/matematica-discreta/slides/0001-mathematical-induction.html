Mathematical induction

By the end you can: write a complete weak-induction proof — base case and inductive step, correctly labelled — for a sum formula, in a form a marker cannot fault.

This deck reviews weak mathematical induction ahead of Test 1. Induction proves a statement for every natural number from some starting point onward, without checking each value one by one. Press N any time to read these notes; → or space advances, ← goes back.

The idea: falling dominoes

Base case: show P(n₀) is true — the first domino falls on its own.

Inductive step: assume P(k) for some fixed k ≥ n₀ (the inductive hypothesis, IH), then show P(k+1) — whichever domino falls, the next one falls too.

Together: the base case falls, and the chain guarantees every later domino falls — so P(n) holds for every n ≥ n₀.

Source: Rosen, Discrete Mathematics and Its Applications, "Mathematical Induction" (RESOURCES.md)

Checking a few values of n is not a proof: it only shows the first few dominoes are the right shape, not that each one topples the next. The base case anchors the chain; the inductive step is what makes it run forever. Note the inductive hypothesis assumes P holds for one arbitrary but fixed k — never for all n, since that would assume the very thing being proved.

Proof skeleton

Source: reference/induction.html, "Proof skeleton"

State the claim, then the four parts in order: base case (plug in n₀ directly), inductive hypothesis ("assume P(k) holds for some fixed k ≥ n₀"), inductive step (derive P(k+1), using the IH somewhere and saying explicitly where), and a conclusion line that names the principle of induction. Skipping the conclusion line, or never actually using the IH in the step, are both common ways to lose marks even when the algebra is right.
Check yourself

In the inductive step, what exactly do you assume?

That P holds for some fixed k ≥ n₀ — not for every k. Assuming "P(n) for all n" would assume the very thing being proved.

This is the single most common way students misstate the inductive hypothesis. You fix one arbitrary but specific k ≥ n₀, and assume only P(k) — then you must derive P(k+1) from it. Answer from memory before revealing.

Worked example: the claim

For every n ≥ 1: 1 + 2 + … + n = n(n+1)/2

We will prove this holds for every n ≥ 1 by weak induction — not by checking values.

Base case (n = 1): LHS = 1. RHS = 1·2/2 = 1. Equal, so P(1) holds.

Source: lessons/0001-mathematical-induction-weak.html, "Worked example"

The base case is the easiest part: plug n₀ = 1 into both sides and check they match. Here the left-hand side is just the single term 1, and the right-hand side is 1·2/2 = 1. This anchors the whole chain of dominoes at n = 1.

Worked example: the inductive hypothesis

Assume, for some fixed k ≥ 1:

1 + 2 + … + k = k(k+1)/2

Goal for the inductive step: use this to show 1 + 2 + … + k + (k+1) = (k+1)(k+2)/2 — i.e. P(k+1).

Source: lessons/0001-mathematical-induction-weak.html, "Worked example"

The inductive hypothesis is just P(k), written out for the specific formula: the sum up to k equals k(k+1)/2. We are allowed to assume this — we are not allowed to assume the general formula for all n. The target is P(k+1): the same formula with k+1 in place of n.

Worked example: the inductive step

1 + 2 + … + k + (k+1)= k(k+1)/2 + (k+1)          [by IH]= (k+1)(k/2 + 1)= (k+1)(k+2)/2

That last line is exactly n(n+1)/2 with n replaced by k+1 — precisely what P(k+1) claims.

Source: lessons/0001-mathematical-induction-weak.html, "Worked example"

Start from the left-hand side of P(k+1): the old sum plus the new term (k+1). Replace "1+…+k" using the inductive hypothesis — that's the highlighted line, and it's where the IH is actually used, which you must say explicitly. Then factor (k+1) out of both terms: k(k+1)/2 + (k+1) = (k+1)·(k/2 + 1) = (k+1)(k+2)/2. This matches the formula n(n+1)/2 at n = k+1, so P(k+1) is proved.
Check yourself

A student checks the formula for n = 1, 2, 3 and writes "it works, so it's proven for all n." What's missing?

The inductive step linking k to k+1. Checking finitely many cases never covers the infinitely many n left untested — only the inductive step closes the gap for every n at once.

A base case alone (even several correct checks) is not induction. Without an inductive step showing P(k) ⟹ P(k+1) for an arbitrary k, there is no guarantee the pattern continues past the values actually checked.

Worked example: the conclusion

Base case holds (n = 1), and P(k) ⟹ P(k+1) for every k ≥ 1.

By the principle of mathematical induction, 1 + 2 + … + n = n(n+1)/2 for all n ≥ 1.

Never skip this line — a proof without a conclusion citing the principle loses marks even if the algebra is correct.

Source: reference/induction.html, "Proof skeleton"

The conclusion is a short, formulaic sentence, but it is a required part of the proof: it explicitly invokes the principle of mathematical induction to justify jumping from "base case + inductive step" to "true for all n ≥ n₀".

Common marks lost

  • No explicit conclusion line citing the principle of induction.
  • Inductive step never actually uses the IH — then it isn't induction.
  • Writing "assume P(n) for all n" instead of "assume P(k) for some fixed k" — this assumes the very thing being proved.
  • Base case checked at the wrong starting value (e.g. n = 0 when the claim says n ≥ 1).

Source: reference/induction.html, "Common marks lost"

These four are the most common ways a mechanically correct-looking proof still loses marks. Read your own proofs against this list before handing them in: does the conclusion name the principle of induction, does the step visibly use "by IH", is the hypothesis about one fixed k, and does the base case match the claim's starting value?
Check yourself

Using the now-proven formula, compute 1 + 2 + … + 10 in one line.

10·11/2 = 55. No need to add ten numbers by hand — that's the payoff of having proved the formula for every n.

Once a formula is proved by induction, you can use it directly for any n ≥ 1 — here n = 10 gives 10·11/2 = 55 in one step, instead of adding ten numbers.

Summary

  • Induction has exactly two parts: a base case, and an inductive step that shows P(k) ⟹ P(k+1) for an arbitrary fixed k ≥ n₀.
  • Write all four labelled parts — base case, IH, step, conclusion — and use the IH explicitly in the step.
  • Checking a few values is never a substitute for the inductive step.
