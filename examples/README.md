# Examples

Real outputs from Hint Ladder, produced in headless test runs on 2026-09-25, when the project was still called CS Tutor (so some outputs name `cs-tutor`) with the curriculum in [`evals/fixtures/curricula/`](../evals/fixtures/curricula/pt-engenharia-informatica-3-anos.txt). Paths are shortened to `~/course`; nothing else was edited, with one exception: quiz 4 of the lesson showed `String[] names;` without the `static` field it came from in Lab 1, which made it a compile error in Java rather than the `NullPointerException` its answer claims. The snippet now shows the field, and `/lesson` now requires every snippet to carry the declarations its behaviour depends on and to be run when the toolchain is installed. The three decks carry the current deck engine (the template's script and its auto-fit rule); their slides are as generated, apart from two that were regenerated before publishing: the first TCP deck had diagrams taller than the stage, and the first induction deck had a muddled strong-induction answer. Both faults led to rule changes in `/slides`.

## In Portuguese: [pt-PT/](pt-PT/)

The same commands in a test course whose `CURRICULUM.md` says `Language: Portuguese (Portugal)`, run on 2026-09-25 with the plugin as named today. Everything is as generated, apart from these hand fixes, each of which also became a rule in the skill that made the fault: in the TCP deck, one label split into two lines and two state boxes widened so no label runs past its figure (slide 2 and 4), and the round-axis label moved off a tick (slide 11); in the induction lesson, "you only know it exists" became "the argument has to work for any k" (the hypothesis is about every k, not some k); in the networks lesson, two arrow labels moved above their arrows. The first runs of `/setup add` and `/progress` replied partly in English (the files they wrote were in Portuguese), and the first `/research` packs had English headings: those skills were fixed, and the interview and the packs here come from the runs after the fix.
