# Examples

Real outputs from CS Tutor, produced in headless test runs on 2026-09-25 with the curriculum in [`evals/fixtures/curricula/`](../evals/fixtures/curricula/pt-engenharia-informatica-3-anos.txt). Paths are shortened to `~/course`; nothing else was edited, with one exception: quiz 4 of the lesson showed `String[] names;` without the `static` field it came from in Lab 1, which made it a compile error in Java rather than the `NullPointerException` its answer claims. The snippet now shows the field, and `/lesson` now requires every snippet to carry the declarations its behaviour depends on and to be run when the toolchain is installed. The three decks carry the current deck engine (the template's script and its auto-fit rule); their slides are as generated, apart from two that were regenerated before publishing: the first TCP deck had diagrams taller than the stage, and the first induction deck had a muddled strong-induction answer. Both faults led to rule changes in `/slides`.
