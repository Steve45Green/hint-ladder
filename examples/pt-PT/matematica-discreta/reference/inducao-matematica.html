Indução matemática

Indução fraca — estrutura da prova

Para provar P(n) verdadeira para todo n ≥ n₀:

  1. Base: mostrar P(n₀) diretamente.
  2. H.I.: assumir P(k) verdadeira para um k ≥ n₀ arbitrário.
  3. Passo indutivo: provar P(k) → P(k+1) usando a H.I.
  4. Conclusão: por indução, P(n) vale para todo n ≥ n₀.

Erros comuns

  • Esquecer a base — sem ela, o "efeito dominó" não tem primeiro dominó.
  • Assumir P(k+1) em vez de P(k) na H.I. (é isso que se quer provar, não assumir).
  • No passo indutivo, não usar a H.I. em lado nenhum — se a H.I. nunca aparece na prova, a prova não é indução.
  • Testar só um valor de k no passo indutivo em vez de argumentar para um k arbitrário.
