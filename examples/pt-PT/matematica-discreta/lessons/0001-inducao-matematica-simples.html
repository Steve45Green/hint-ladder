Indução matemática simples (fraca)

No final consegues: escrever, do zero e em papel, uma prova completa por indução fraca de uma fórmula de soma — com base, hipótese de indução e passo indutivo todos justificados, sem saltar nenhum.

A ideia

Indução serve para provar que uma afirmação P(n) é verdadeira para todos os inteiros n a partir de um certo n₀ (normalmente 0 ou 1) — não conseguimos testar infinitos casos um a um, por isso provamos que o primeiro é verdadeiro e que cada caso "empurra" o seguinte.

Rosen, Discrete Mathematics and Its Applications) — não confirmada contra o material específico da cadeira. Confirma a notação usada nas aulas assim que puderes.

Uma prova por indução fraca tem sempre três partes, nesta ordem:

  1. Base: provar P(n₀) diretamente (substituindo o valor).
  2. Hipótese de indução (H.I.): assumir que P(k) é verdadeira para um k ≥ n₀ arbitrário — não escolhes um k em particular: o argumento tem de servir para qualquer k ≥ n₀.
  3. Passo indutivo: usando a H.I., provar que P(k+1) também é verdadeira. Isto é provar a implicação P(k) → P(k+1) — a mesma noção de implicação da lógica proposicional que já viste nas tabelas de verdade.

Concluis: por indução, P(n) é verdadeira para todo o n ≥ n₀.

Exemplo resolvido

Provar que, para todo n ≥ 1: 1 + 2 + ⋯ + n = n(n+1)/2.

Base (n = 1): lado esquerdo = 1; lado direito = 1·2/2 = 1. Iguais. ✓

H.I.: assume-se que, para um certo k ≥ 1, 1 + 2 + ⋯ + k = k(k+1)/2.

Passo indutivo: quer-se mostrar 1 + 2 + ⋯ + (k+1) = (k+1)(k+2)/2.

Como a base se verifica e P(k) → P(k+1) é verdadeira para qualquer k ≥ 1, por indução a fórmula é verdadeira para todo n ≥ 1.

Prática

1. Numa indução fraca para provar P(n) com n ≥ 1, que valor de n testas na base?

A base testa sempre o menor valor de n para o qual P(n) deve valer — aqui n = 1.

2. Na hipótese de indução, o que assumes exatamente?

A H.I. não fixa um k específico — é um k arbitrário, e é precisamente por isso que o passo indutivo, uma vez provado, vale para toda a cadeia de dominós.

3. (Ligação à lógica proposicional) O passo indutivo consiste em provar qual proposição?

O passo indutivo é uma implicação: não afirmas P(k) nem P(k+1) isoladamente, só que, se P(k) vale, então P(k+1) também vale — a mesma implicação → das tabelas de verdade.

4. No passo indutivo do exemplo resolvido, depois de aplicar a H.I. temos k(k+1)/2 + (k+1). Qual é a forma fatorizada final (igual a P(k+1))?

Pondo (k+1) em evidência: (k+1)(k/2 + 1) = (k+1)(k+2)/2 — exatamente a fórmula com n substituído por k+1.
