Three-way handshake

passodireçãoflagso que faz
1cliente → servidorSYNpropõe seq = ISN_c
2servidor → clienteSYN, ACKpropõe seq = ISN_s, confirma ack = ISN_c + 1
3cliente → servidorACKconfirma ack = ISN_s + 1

Regra: ack = seq recebido + 1. Um SYN não transporta dados mas consome um número de sequência.
