Key facts

  • HTTP is stateless: no request is linked to any other unless the application adds cookies or a token.
  • HTTP runs inside a TCP connection — TCP carries the bytes; HTTP is the text format.
  • Since HTTP/1.1, a single TCP connection can carry several requests in sequence (persistent connections).
