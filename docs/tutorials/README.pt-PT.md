# Tutoriais

*[English](README.md)*

Passo a passo, do "o que é isto?" até à rotina de cada semana. Cada tutorial diz quanto tempo demora, o que precisas e o que deves ver quando um passo correu bem.

| # | Tutorial | Para | Tempo |
|---|---|---|---|
| 0 | [O que é o CS Tutor?](0-what-is-it.pt-PT.md) | qualquer pessoa, sem conhecimentos técnicos | 3 min |
| 1 | [Instalar o Claude Code e o CS Tutor](1-install.pt-PT.md) | alunos, em Windows, macOS ou Linux | 10 min |
| 2 | [Configurar o teu curso](2-set-up-your-course.pt-PT.md) | alunos, uma vez por ano | 10 min |
| 3 | [Um dia de estudo](3-a-study-day.pt-PT.md) | alunos, todos os dias | 15–30 min |
| 4 | [Trabalhos avaliados: o que faz e o que não faz](4-graded-work.pt-PT.md) | alunos com um trabalho, projeto ou apresentação | 10 min |
| 5 | [Todas as semanas: `/progress` e depois `/research`](5-every-week.pt-PT.md) | alunos, uma vez por semana | 20 min |
| — | [Resolução de problemas](troubleshooting.pt-PT.md) | quando algo não funciona | — |

Docentes: ver [Para docentes](../para-docentes.pt-PT.md). Referência de todos os comandos: [o guia](../GUIA.pt-PT.md).
