Start in three steps

You need Claude Code and a paid Claude plan (Pro or higher); Hint Ladder itself is free.

claude plugin marketplace add Steve45Green/hint-ladder
claude plugin install hint-ladder@hint-ladder

Then /setup once (paste your course units), open a unit's folder, and type /go every day. Step by step: the tutorials.
